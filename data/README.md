# Data

**Source:** the `ALL` dataset (Chiaretti et al., 2004), distributed as the Bioconductor R package `ALL`.

**Used here:** the 94 B-cell patients whose subtype is BCR/ABL, ALL1/AF4, E2A/PBX1 or NEG, with 12,625 gene measurements each. Expected class counts: NEG 42, BCR/ABL 37, ALL1/AF4 10, E2A/PBX1 5.
